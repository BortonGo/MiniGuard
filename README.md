# MiniGuard

MiniGuard — учебный Linux Endpoint Security Agent на C++20. Главная цель проекта —
освоить системное программирование Linux и уметь объяснить архитектурные решения на
техническом собеседовании.

Проект развивается постепенно: теория → небольшая самостоятельная реализация →
разбор → исправление → проверка через Linux-инструменты.

## Текущая среда

```text
Mac или Windows
  └─ VS Code
       └─ Remote SSH
            └─ Ubuntu VM в Hyper-V на Windows
                 ├─ исходники MiniGuard
                 ├─ GCC / Clang
                 ├─ CMake / Ninja
                 ├─ GDB / strace / Valgrind
                 └─ Linux kernel
```

Сборка, запуск и отладка выполняются в Ubuntu. Mac и Windows используются как
клиенты VS Code. Пока используется одна VM, Windows-компьютер и Ubuntu VM должны
быть включены для работы с Mac.

## Как продолжать работу

1. Открыть [`ROADMAP.md`](ROADMAP.md) и найти блок **Текущий фокус**.
2. Подключиться к Ubuntu через VS Code Remote SSH.
3. Перед изменениями выполнить `git pull --ff-only` в Ubuntu.
4. Сделать одну небольшую учебную задачу.
5. Проверить сборку и тесты.
6. Обновить чекбоксы и журнал в `ROADMAP.md`.
7. Создать отдельный логический commit и выполнить `git push`.

Подробности подключения находятся в
[`docs/environment.md`](docs/environment.md). Для первого запуска на Windows
используйте готовый промт из
[`docs/windows-vscode-handoff.md`](docs/windows-vscode-handoff.md).

## Важные правила

- Не хранить в Git пароли, приватные SSH-ключи, токены и файлы с секретами.
- Не писать большие компоненты целиком без разбора Linux API.
- Не создавать всю будущую структуру каталогов заранее.
- Не использовать реальные вредоносные программы.
- Kernel module разрабатывать только после userspace-части.
- Один commit должен соответствовать одной понятной задаче.

Исходный код намеренно ещё не добавлен: первый CMake-проект и первая программа
будут созданы владельцем проекта как часть этапа 0.
